# batade

Creates HTML reports from R.

Compatibility updates by Renova.

Removes the extra hwriter attachment and cleans up the HTML report documentation and package metadata.

## Installation

```r
install.packages("batade", repos = c(
  Renova = "https://renova-r.r-universe.dev",
  CRAN = "https://cloud.r-project.org"
))
```

Version `0.1.9001` is based on [CRAN 0.1](https://cran.r-project.org/package=batade).
